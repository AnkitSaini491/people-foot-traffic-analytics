# people-foot-traffic-analytics
A real-time People Detection, Tracking and Foot Traffic Analytics system built using Python, OpenCV and YOLO.
People Foot Traffic Analytics

A real-time People Detection, Tracking and Foot Traffic Analytics system built using Python, OpenCV and YOLO.

Features

- Real-time person detection
- Multiple-person tracking
- Unique ID tracking using ByteTrack
- IN/OUT people counting
- Movement trajectory tracking
- Perspective/vision-point visualization
- Scene map visualization
- Foot traffic dashboard
- Processed video output

Technologies Used

- Python
- YOLO
- OpenCV
- NumPy
- ByteTrack

Project Structure

people-foot-traffic-analytics/
│
├── main.py
├── requirements.txt
├── README.md
└── .gitignore

Installation

Clone the repository:

git clone https://github.com/YOUR_USERNAME/people-foot-traffic-analytics.git

Go to the project directory:

cd people-foot-traffic-analytics

Install the required libraries:

pip install -r requirements.txt

Run the Project

Place your input video in the project folder and rename it:

input.mp4

Run:

python main.py

The processed video will be saved as:

output.mp4

Output

The system displays:

- Person bounding boxes
- Person tracking
- Movement paths
- IN/OUT counts
- Vision point
- Perspective lines
- Scene map
- Foot traffic statistics

Use Cases

This project can be used for:

- Retail store analytics
- Mall visitor counting
- CCTV analytics
- Crowd monitoring
- Building entrance monitoring
- Foot traffic analysis
